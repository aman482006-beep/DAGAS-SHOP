# DAGAS SHOP — Wholesale Kidswear Platform

Official B2B ecommerce catalogue, lead generation, and bulk manufacturing showroom platform for **DAGAS SHOP** located in Sultanpete, Bengaluru, Karnataka, India.

> **Business Identity**: DAGAS SHOP is an independent kidswear wholesale supplier and bulk manufacturer based in Mohana Square, Sultanpete, Bengaluru. It is not affiliated with DAGAS FASHION or any other similarly named entity.

---

## 🌟 Key Features

- **B2B Wholesale Showroom**: Fast, responsive product catalog with zero consumer checkout friction. Default action is *"Enquire on WhatsApp"* or *"Request Catalogue"*.
- **Flexible Quantities & No Rigid MOQ**: Convenient size-ratio wholesale bundles (₹300 – ₹600+ price range).
- **Global Export Corridors**: Dedicated international buyers portal with active shipping to **Uganda**, **Malaysia**, **Sri Lanka**, and worldwide.
- **Bulk Manufacturing Funnel**: 7-step production lifecycle for qualified buyer requirements.
- **Sultanpete Showroom Location**: Verified physical address, opening hours, and interactive Google Map integration.
- **Genuine Google Reviews**: Authentic ratings and feedback directly from Google Business Profile (Place ID: `ChIJ47LHNQgWrjsRV0ikmlBQlEY`).
- **Comprehensive SEO & Schema.org**: JSON-LD (`Organization`, `LocalBusiness`, `Product`, `BreadcrumbList`, `FAQPage`, `WebSite`), dynamic XML sitemap, and robots.txt.
- **Mobile-First UX**: Fast tap targets, sticky mobile WhatsApp CTA, and lightweight bundles (< 88 kB first load JS).

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14.2 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Analytics**: GA4, Meta Pixel, and custom conversion event tracking

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
